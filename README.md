## Purpose

NOEPIN AL is a collection of general-purpose control, safety, state, reconstruction, and optimization technologies developed in the course of NOEPIN / のえぴん's game-development work.

This repository publishes the technologies themselves. **MOFUMORI / もふもふの森, RUFA, game-specific runtime, scenarios, character data, world data, and unreleased game assets are not included.**

## 公開方針 / Publication policy

検証済みのSuccessor V2 / V3などの成果物は、正式な完成記録として管理しています。

GitHubには、その検証済み成果物のうち、**内容を変更せずにそのまま移せるものから順次公開**しています。READMEなどの文書をもとに似たコードを再生成し、それを「検証済みの完成版」として置き換えることはしていません。

各番号の **COMPLETE / VERIFIED** は正式な完成記録に基づく状態です。GitHub上では、説明用READMEと、正確に移送できたVerification Report / Artifact Sealなどの証跡を公開しています。さらに、Final ZIPから内容を変更せず正確に移送できた検証済みソースは `verified_artifact/` として公開しています。正確に移送できないソースやZIPを、文書から作り直して補完することはしません。

各技術は、独立した作品ページと技術証跡フォルダに分けて公開しています。
